Desktop: hover a column to preview, click to drop. Mobile: drag over a column, let go to drop, or drag off the board to cancel.
Easy: random column. Medium: wins or blocks when it can and avoids setting you up. Hard: minimax with alpha-beta pruning, looking several moves ahead (fewer on wider boards so it stays quick). Impossible: the robot searches every move it can, up to 10 seconds per move, and stops early when it has proven the best move. It gets no extra pieces. The first player has the advantage in Connect 4, so set Goes first to Robot for the toughest game. When a game ends you can save it as JSON, load a saved game and replay it, or use Instant replay for the latest match. Two players: take turns on one screen.
