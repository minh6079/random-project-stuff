Easy: random moves. Medium: wins or blocks when it can, otherwise random. Hard: on 3×3 it searches every possible game and never loses. On bigger grids it looks a few moves ahead with alpha-beta pruning and scores every possible line. Impossible: the robot searches every move it can: a complete, perfect search on 3×3, and up to 10 seconds of the deepest search it can manage on bigger boards. It gets no extra marks, so set Goes first to Robot for the toughest game. When a game ends you can save it as JSON, load a saved game, and replay it, or use Instant replay for the latest match. Two players: take turns on one screen.
